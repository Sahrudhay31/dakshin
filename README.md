## Features

### 1. Interactive Map
- SimpleMaps integration displaying all South Indian states
- Click on any state to explore its destinations
- Visual representation of geographical locations

### 2. Destinations Database
- 30 handpicked destinations across 5 states
- 6 destinations per state (Kerala, Tamil Nadu, Karnataka, Telangana, Andhra Pradesh)
- Each destination includes:
  - 3 high-quality images in carousel
  - Detailed overview and highlights
  - 5 nearby places with distances
  - Transport information (airport, railway, bus)
  - Accommodation options and price ranges
  - Google Maps location embedding
  - User ratings (4.4 to 4.9 stars)

### 3. Search and Filter System
- Real-time search by destination name or state
- Category filtering (Beach, Hill Station, Temple, Wildlife)
- Instant results display without page reload

### 4. Tour Packages
- 5 curated packages (one per state)
- Package durations: 4-6 days
- Detailed day-by-day itineraries
- Complete inclusions and exclusions list
- Hotel recommendations with amenities
- Local cuisine suggestions
- Dynamic pricing based on passenger count

### 5. Smart Trip Planner
- Step 1: Select destination state
- Step 2: Choose duration (3-7 days), budget, travel style, and travelers
- AI-powered itinerary generation
- Real-time cost calculation
- Day-by-day activity planning
- Hotel and food recommendations
- Save itinerary as text file

### 6. User Authentication System
- User registration with name, username, email, and password
- Secure login system
- Password strength validation
- Session management using localStorage
- Profile viewing functionality

### 7. Booking and Payment System
- Passenger count selection (1-20 travelers)
- Travel date picker
- Multiple payment methods (Card, UPI, Net Banking)
- Booking confirmation and storage
- View all bookings in "My Bookings" section

### 8. Responsive Design
- Fully responsive across all devices
- Mobile-optimized layouts
- Tablet and desktop breakpoints
- Touch-friendly navigation

## Destinations Covered

### Kerala (6 Destinations)
1. Alleppey Backwaters - Houseboat Paradise
2. Munnar - Tea Gardens Paradise
3. Kovalam Beach - Golden Beach
4. Varkala - Cliff Beach
5. Thekkady - Wildlife Sanctuary
6. Wayanad - Forests and Waterfalls

### Tamil Nadu (6 Destinations)
1. Meenakshi Temple - Architectural Wonder
2. Ooty - Queen of Hills
3. Marina Beach - Longest Beach
4. Kodaikanal - Princess of Hills
5. Rameshwaram - Holy Island
6. Mahabalipuram - Rock Cut Temples

### Karnataka (6 Destinations)
1. Hampi - UNESCO Ruins
2. Coorg - Coffee Plantations
3. Mysore Palace - Royal Palace
4. Bandipur - Wildlife Park
5. Badami Caves - Ancient Temples
6. Gokarna - Spiritual Beach

### Telangana (6 Destinations)
1. Charminar - Icon of Hyderabad
2. Golconda Fort - Historic Fort
3. Ramoji Film City - Film Studio
4. Birla Mandir - Marble Temple
5. Hussain Sagar - Lake and Buddha
6. Ramappa Temple - UNESCO Temple

### Andhra Pradesh (6 Destinations)
1. Tirupati - Spiritual Center
2. Visakhapatnam Beach - Coastal Beauty
3. Araku Valley - Hill Station
4. Srisailam - Jyotirlinga Temple
5. Lepakshi - Hanging Pillar
6. Gandikota - Grand Canyon
